# Código de conduta

Participantes devem manter colaboração respeitosa, inclusiva e fundamentada. Assédio, ataques pessoais, divulgação de segredos ou uso do repositório para direcionar exploração não autorizada não serão aceitos. Questões de segurança devem ser relatadas privadamente conforme `SECURITY.md`. Para contato inicial, abra issue sem informações sensíveis.
